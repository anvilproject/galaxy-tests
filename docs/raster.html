Longitudinal tool-test results for the anvilproject/galaxy-tests CI pipeline. Color shows result type and intensity shows the fraction of tests affected. Hover a cell for the exact numbers; click it to see that tool's failing tests and their tracebacks. Tools appear the first time they're actually tested, so the row list grows over time rather than starting from a fixed list. The bar above each run column shows how many tools it affected and how much of the toolset it actually covered (click it for a run-wide breakdown); the bar to the right of each tool shows how often that tool has had trouble over the runs currently shown (click it, or the tool's name, for that tool's history).
