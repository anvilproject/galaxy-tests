Each row is a tool, each column a test run (oldest to latest, left to right). Color shows what happened; intensity shows how much of the tool was affected. Hover a cell for the exact numbers; click it to open that run's full report. Tools appear the first time they're actually tested, so the row list grows over time rather than starting from a fixed list. The bar above each run column shows how many tools it affected and how much of the toolset it actually covered; the bar to the right of each tool shows how often that tool has had trouble over the runs currently shown. Hover either for details.
