What each run costs in GCP compute, and where it goes.

Costs are GCP compute list prices reported by the instance's Rainstone deployment (CPU and RAM only; persistent disk, external IP, and network egress are excluded), applied to each run's measured machine shapes and observed GCE VM lifetimes. The shared deploy node's cost runs from launch until this data is collected just before teardown. Each GCP Batch job gets its own dedicated VM; its lifetime is measured from Rainstone's observed GCE instance start to deletion and split by Rainstone into boot (GCE start to tool start), run (tool execution), idle (between retries on the same VM), and teardown (tool finish to GCE deletion), each with its own cost. Runs recorded after billing export completes also show a side-by-side comparison against GCP BigQuery billing (`cost_at_list`). See anvil_generate_cost_data.py for how Rainstone's API is queried.
