What deserves attention in this run, and why.

The tool x run raster answers "what happened where?" - this page answers "what needs attention now, is it new or recurring, and is it one shared incident or many independent tool problems?" Individual failing/erroring tests are clustered by a normalized signature (the sharpest available error message, with random paths/IDs scrubbed out), so a single bug affecting many tools reads as one incident instead of dozens of unrelated-looking rows. Each incident carries a suspected source and confidence rather than an opaque severity score - "Unknown" is used deliberately whenever the evidence doesn't support a more specific guess.
